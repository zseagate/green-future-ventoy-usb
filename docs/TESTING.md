# 测试清单

> 测试前先备份，先在测试机验证，不要直接拿生产机器试。  
> Legacy 和 UEFI 是两条独立启动链，必须分别测试。

## 1. 测试环境

| 项目 | 建议 |
|---|---|
| 测试机 | 一台支持 Legacy 的旧机 + 一台支持 UEFI 的新机，或虚拟机 |
| 固件 | Legacy/CSM 开启；UEFI 模式单独测试 |
| Secure Boot | 如启动失败，先在固件中关闭 Secure Boot 再测 |
| 显示器 | 至少测试一台低分辨率老屏和一台普通显示器 |
| 网络 | PE 联网工具可选测试，不要求全部联网 |

## 7. 通过标准

- 主菜单在 Legacy 和 UEFI 下都能显示；
- 菜单项能覆盖 PE、系统安装、Linux Live、维护工具四类；
- 关键 PE 能进桌面；
- 系统安装镜像能进安装界面；
- Linux Live 镜像能进桌面；
- 维护工具能进入主界面；
- 没有出现“选择镜像后直接重启/黑屏/找不到镜像”的普遍问题。

## 8. 常见失败现象

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 菜单不显示中文 | `ventoy.json` 未加载/编码错误 | 检查 JSON 语法和 UTF-8 |
| 菜单只有默认项 | `menu_alias` 路径不匹配 | 运行 `validate-menu.ps1` |
| Legacy 能启动，UEFI 不能 | VTOYEFI 分区缺失/损坏 | 重新安装 Ventoy |
| UEFI 能启动，Legacy 不能 | MBR/CSM 设置或镜像仅 UEFI | 检查固件和镜像 |
| 选镜像后黑屏 | 镜像引导结构不完整 | 用 7-Zip 检查 `EFI` / `isolinux` |
| Live 镜像 UEFI 失败 | 镜像无 EFI 引导 | 改用 Legacy，属预期 |
| 旧系统 UEFI 失败 | 旧系统 UEFI 支持有限 | 改用 Legacy |
| 文件复制后大小不一致 | 复制中断/空间不足 | 重新复制并校验 |
| 时间戳不一致 | exFAT 2 秒精度 | 正常，不影响启动 |
